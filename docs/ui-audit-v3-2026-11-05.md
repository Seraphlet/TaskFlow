# Toward the Sea｜UI/UX V3 审计与验收记录

日期：2026-11-05

## 修改前审计

- 主导航固定展开，工作页面缺少轻量收起能力。
- Notes 与 Templates 已有列表区，但没有独立折叠状态；Radar 的方向配置和历史占用主内容纵向空间；Settings 同时铺开全部卡片。
- 工作页仍混用早期深色、珊瑚色按钮和较重卡片，层级不够统一。
- Home 和数字艺术复用 App Shell，若直接覆盖全局 `.sidebar`、`.main` 或 `.card` 会造成明显回归。
- 劳动与生活工资记录使用日期范围及 1.5 / 2 / 3 倍工时字段，与新的按月语义存在冲突；旧数据不能直接套用新公式。

## 实施边界

- Fluent / Mica 视觉只作用于非 Home、非 Playground 路由。
- 不重构 IndexedDB、Storage Adapter、Notes / Radar / Task 业务协议。
- 工资记录新增 `recordVersion: 2` 和 `formulaVersion: 2`；旧记录继续走兼容公式与原字段编辑。
- 新记录按月份去重，编辑保留原 ID 与创建时间。

## 主要结果

- 桌面主导航支持折叠；移动端沿用原响应式导航。
- Notes、Templates、Radar、Settings 的内容侧栏独立控制，互不共享状态。
- Radar 历史按当前方向在 Drawer 中查看。
- 模板详情原位编辑，新建模板为居中模态框。
- Settings 每次只展示当前分类，原配置项、保存动作与凭证策略保持不变。
- 工资 V2 区分实际工时、加权估算工时和理论加班收益，周末及节假日不重复计入实际总工时。
- 加班历史与试算区明确分离，历史快照可只读查看。

## 风险控制

- Home 与数字艺术使用结构条件和 CSS 路由作用域双重隔离。
- 旧工资记录不批量迁移、不自动重算。
- 模板、Radar、Settings 只调整信息架构，不更改存储键或服务接口。
- 新增 UI 契约测试，防止后续误删隔离选择器和关键交互入口。

## 验收口径

自动化覆盖语法、工资计算边界、旧数据分派、月份去重和 UI 结构契约。浏览器检查覆盖 Home / 数字艺术隔离、工作页横向溢出、内容侧栏、Radar 历史、模板模态框、工资新增/原位编辑/重复月份拦截与旧记录兼容提示。

## 实际验收结果

- 20 组 JavaScript 测试通过。
- Python：25 passed，4 subtests passed；保留 1 条既有 Starlette TestClient 弃用警告。
- `node --check js/app.js`、`node --check js/labor-life.js` 与 `git diff --check` 通过。
- 662px 窄屏实测 Home、数字艺术和所有抽查工作页均无横向溢出。
- Home 与数字艺术不存在工作页主导航折叠按钮；Music Geometry 动态加载后正常创建 Canvas。
- 工资 V2 实测保存 210 小时记录、原位修改后同月份仍只有 1 条，重复新建会明确拦截；旧工资记录显示兼容模式。
- 设置分类切换后只显示目标卡片；模板新建模态框使用 Slate 主按钮；Radar 历史和加班历史快照可在 Drawer 中查看。
- 浏览器控制台无 warning / error。
